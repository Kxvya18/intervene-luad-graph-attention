Paper-facing IBPA-v2 claim
==========================

Claim: IBPA-v2 is a physics-guided interleaved attention discovery framework, not a generic supervised PRISM predictor. It uses thermodynamic residual and biological module states as a weak prior, learns interleaved module attention by reconstructing biological-physics module states, and validates the learned state against held-out interpretation endpoints from PRISM.

Main discovery: high IBPA-v2 state marks an NSCLC SREBP/mitochondrial/oxidative stress-survival vulnerability state. The high-vs-low state difference for cytotoxic-residual stress-survival is 1.005 (permutation p=0.0004). Generic cytotoxic response is not enriched (-0.102, p=0.3417), and direct lipid response is weaker (0.060, p=0.1812).

Ablation warning:
Because the learned state is physics-guided, the paper should explicitly report raw-prior and prior-weight ablations. IBPA-v2 should be described as semi-supervised or physics-guided, not fully unsupervised.

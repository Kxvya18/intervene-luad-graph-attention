Interpretation
--------------
This V2 experiment tests whether richer gene-level tokens, clinical adjustment, multitask supervision, and biology-guided attention make the AI component stronger. The strongest model should ideally improve C-index while also increasing biology-edge attention gain. If edge gain improves without C-index improving, the constrained model is more interpretable but not more predictive.
